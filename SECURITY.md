# Политика безопасности (Security Policy)

## Поддерживаемые версии
Безопасность обновлений гарантируется только для последней версии (v1.1+).

## Сообщение об уязвимости
Если вы обнаружили уязвимость (например, проблему с безопасностью при применении JSON), пожалуйста, **не создавайте публичный Issue**. 
Вместо этого напишите на почту разработчику.

Мы постараемся ответить в течение 48 часов.
