# Как внести вклад (Contributing)

Мы приветствуем вклад в развитие Codegen Studio!

## Процесс
1. Сделайте форк репозитория.
2. Создайте ветку для новой функции (`git checkout -b feature/my-feature`).
3. Напишите код и обязательно добавьте/обновите тесты (если есть).
4. Убедитесь, что код проходит линтинг (`ruff check .`).
5. Обновите документацию (если изменилось поведение).
6. Сделайте коммит и отправьте Pull Request.

## Стиль кода
- Следуйте PEP 8.
- Используйте `ruff` для форматирования.
- Пишите комментарии на русском языке.
