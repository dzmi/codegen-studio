# Контекст проекта (для ИИ)

## Краткая выжимка для ИИ

**Codegen Studio** — офлайн-инструмент на Python 3.10+ / Tkinter для применения JSON-инструкций к коду. Работает без встроенного ИИ: пользователь копирует готовый промпт в ChatGPT/Claude/LM Studio, получает JSON, вставляет в Studio, проверяет diff и применяет.

**Стек:** Tkinter (stdlib), pygments (опц., подсветка), dulwich (опц., Git). Обязательных зависимостей — ноль.

**Архитектура:**
- `codegen_core.py` — ядро: `normalize_actions` → `validate` → `simulate` → `apply_simulation` (с `.bak` и атомарным откатом). **Не импортирует tkinter.**
- `ui_main.py` — весь GUI, включая toolbar-режим и diff-окно.
- `exporter.py` — экспорт JSON/ZIP с единым фильтром `.gitignore` (тот же, что для дерева UI).
- `git_py.py` — dulwich → subprocess git → offline.
- `logger.py` — `logs/studio_app.log` (INFO+) и `logs/studio_errors.log` (WARNING+), ротация 5 МБ × 5.

**Ключевые правила (обязательны при правках):**
1. Любое изменение файла — только через `simulate` → пользователь подтверждает diff → `apply_simulation`.
2. `apply_simulation` атомарна: `.bak` восстанавливаются при любой ошибке, созданные файлы удаляются.
3. `.gitignore` — единственный источник правды. Что не видно в дереве — не попадает в экспорт.
4. Обновления GUI из фоновых потоков — только через `self.root.after()`.
5. `codegen_core.py` не должен импортировать `tkinter`.

**Формат JSON-инструкций:** `{"actions": [{"type": "...", "file": "...", ...}]}`. Предпочтителен `replace_symbol` (через AST, не требует копирования старого кода) над `replace_block` (требует дословного `old`).

**Подробности:** `docs/ARCHITECTURE.md`, `docs/JSON_FORMAT.md`, `docs/GUIDELINES.md`.

## 1. Цель проекта

Дать разработчику **контролируемый** способ применять изменения от внешней LLM к коду:
- Без нагрузки на локальный GPU.
- Без утечки кода в приложение.
- С гарантированным откатом при ошибке.
- С визуальным diff перед каждой записью на диск.

## 2. Предметная область

- **Домен:** AI-assisted coding, локальные офлайн-инструменты.
- **Роль LLM:** любая (ChatGPT, Claude, LM Studio, Ollama, локальная).
- **Связь с LLM:** только через буфер обмена (промпт → LLM → JSON → вставка).
- **Ключевые термины:** Codegen, `replace_symbol`, `replace_block`, симуляция, транзакция, diff, toolbar-режим.

## 3. Технические ограничения

- Python 3.10+.
- Tkinter — stdlib, без внешних GUI-библиотек.
- Никакого сетевого кода — только HTTP через браузер пользователя.
- Логи в `<project>/logs/`, дампы в `<project>/dumps/`.
- Никогда не писать за пределы `project_path` (проверка в `validate`).
