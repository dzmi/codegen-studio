# Рабочий процесс (Workflow)

## Шаг 1: Генерация промпта
1. Вкладка **Промпт**.
2. Выберите шаблон (Codegen, Code review, Архитектура, General).
3. Нажмите **+ Дерево проекта** или **+ Файл**, чтобы добавить контекст.
4. Скопируйте промпт.

## Шаг 2: Работа с LLM
Вставьте промпт в любую нейросеть (ChatGPT, Claude, LM Studio) и допишите задачу.
Модель вернет JSON-инструкции.

## Шаг 3: Применение изменений
1. Нажмите **Вставить JSON** и вставьте ответ модели.
2. Нажмите **Применить**.
3. Программа проверит синтаксис и откроет окно сравнения (Diff).
4. Слева — старый код, справа — новый.
5. Нажмите **Применить изменения**, если всё верно.

## Шаг 4: Откат (если нужно)
Если что-то сломалось — закройте приложение, удалите `.codegen.bak` или используйте Git (`git reset --hard HEAD`).
