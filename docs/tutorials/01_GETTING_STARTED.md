# Начало работы

## 1. Установка
Установите опциональные зависимости (подсветка и Git):
```bash
pip install pygments dulwich
```

## 2. Запуск
Запустите приложение из корня проекта:
```bash
python main.py
```

## 3. Первый проект
1. Нажмите **Проект** в верхнем меню.
2. Выберите папку с вашим кодом.
3. Приложение создаст папки `logs/` и `dumps/`, а также добавит их в `.gitignore`.

## 4. Использование
Основной сценарий: **Промпт -> LLM -> JSON -> Diff -> Apply**.
1. Откройте вкладку **Промпт**, выберите нужный промпт и нажмите **+ Дерево**.
2. Вставьте промпт в ChatGPT/Claude, получите JSON.
3. Нажмите зеленую кнопку **Вставить JSON**, проверьте diff и нажмите **Применить изменения**.
