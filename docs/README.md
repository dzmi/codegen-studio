# 📚 Документация Codegen Studio

Эта папка содержит полную документацию по проекту.

## 📂 Структура

| Файл | Назначение |
|------|-----------|
| `INDEX.md` | Оглавление — начни отсюда |
| `USER_GUIDE.md` | Что это, как запустить, первый проект |
| `WORKFLOW.md` | Пошаговый процесс: промпт → LLM → JSON → diff → apply |
| `JSON_FORMAT.md` | Формат JSON-инструкций, все типы действий |
| `DIFF_DIALOG.md` | Как читать окно сравнения, подсветка, поиск |
| `SETTINGS.md` | Настройки, toolbar-режим, файлы состояния |
| `ARCHITECTURE.md` | Модули, слои, 6 принципов |
| `EXTENDING.md` | Как добавить тип действия, промпт, настройку |
| `TROUBLESHOOTING.md` | Проблемы и решения |
| `PROJECT_CONTEXT.md` | Краткая выжимка для ИИ (сжатая, для экономии токенов) |
| `CHANGELOG.md` | История изменений |
| `GUIDELINES.md` | Правила разработки |

## 🛡️ Правила

1. **PROJECT_CONTEXT.md** содержит блок «Краткая выжимка для ИИ» — именно он уходит в LLM при копировании промпта. Не раздувай его, держи сжатым.
2. **ARCHITECTURE.md**, **DATA_FLOW** (если появится), **CHANGELOG.md** — «живые» документы, перезаписываются при крупных изменениях.
3. В каждом файле в конце маркер `<!-- END OF DOC -->`. Codegen использует его для безопасного добавления записей через `insert_before`.
4. При добавлении новой функции/класса в код — обнови **ARCHITECTURE.md**. При добавлении типа действия — **JSON_FORMAT.md**. При изменении поведения — **CHANGELOG.md**.
