# Окно сравнения (Diff)

Открывается после нажатия кнопки «Применить» (если JSON валиден).

## Структура
- **Левая панель:** Список файлов и конкретных изменений (`✏ стр. 5: изменить`, `➕ добавить`, `➖ удалить`).
- **Центр:** Старый код.
- **Правая панель:** Новый код.

## Подсветка
- 🟡 **Желтый** — строка изменена.
- 🔴 **Красный** — строка удалена (видна только слева).
- 🟢 **Зеленый** — строка добавлена (видна только справа).

## Поиск
Вверху окна есть поле поиска. Введите текст и нажмите `Enter`, чтобы перейти к следующему совпадению (оранжевая подсветка). Счетчик показывает `3/12` (третье из двенадцати).

## Кнопки
- **✅ Применить изменения:** Записывает файлы на диск (создает бэкапы `.bak`).
- **❌ Отмена:** Ничего не применяет.
