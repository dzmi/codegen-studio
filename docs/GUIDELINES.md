# Правила разработки

## 1. Железные правила

1. **Любая запись файла — через `apply_simulation`.** Не пиши на диск напрямую из GUI.
2. **`codegen_core.py` не импортирует `tkinter`.** Ядро должно быть тестируемо отдельно.
3. **`.gitignore` — единственный источник правды.** Если файл невидим в дереве — он не должен попасть в экспорт. Менять только через `exporter.should_include`.
4. **Логи в `<project>/logs/`.** Не писать в stdout без прохождения через `logger`.
5. **`apply_simulation` — атомарна.** `.bak` при любой ошибке должны восстанавливаться, созданные файлы — удаляться.

## 2. Правила для Codegen (промпты для LLM)

- **`replace_symbol` vs `replace_block`:**
  - `replace_symbol` — только для `def` и `class`, через AST, **не требует** копирования старого тела.
  - `replace_block` — для переменных, констант, словарей, частичного кода. `old` — дословная копия.
- **Дословный `old`:** каждый пробел, кавычка, отступ имеют значение. Не нормализуй.
- **Экранирование в JSON:** `"` → `\"`, `\\` → `\\\\`, `\n` → `\n`.
- **Tkinter:** любые обновления GUI из фонового потока — только через `self.root.after()`.

## 3. Архитектурные ограничения

- **Менеджеры компоновки:** не смешивать `pack` и `grid` в одном контейнере.
- **Импорты:** внутри `AI_lite` — плоские (запуск через `main.py` в корне). Не путать с `AI/lmcoder_editor_modular/` — там своя логика.
- **Конфликт имён:** `syntax_highlighter.py` в `AI` и `lite_highlighter.py` в `AI_lite` — не пересекаются. Не переименовывай без причины.
- **`dumps/` и `logs/`:** всегда в `DEFAULT_EXCLUDES`. Не включать в экспорт даже принудительно.

## 4. Окружение

- **Python 3.10+.** На 3.9 не тестировался.
- **Обязательных пакетов нет** (только stdlib).
- **Опционально:** `pygments>=2.19`, `dulwich>=0.21`.
- **Линтер:** `ruff check .` (в `requirements.txt` не требуется — это dev-инструмент).

## 5. Правила безопасной самомодификации

1. **Git commit** перед правкой `codegen_core.py` или `ui_main.py`.
2. **Проверка после правки:** `python -m py_compile <файл>`.
3. **После применения Codegen JSON** — всегда `python main.py` и проверка дерева/вкладок.
4. **При ошибке** — `git reset --hard HEAD` (если был коммит).

## 6. Что нельзя менять без осторожности

| Файл / функция | Почему |
|----------------|--------|
| `codegen_core.apply_simulation` | Транзакционность, `.bak`, откат — легко сломать |
| `exporter.should_include` | Единый фильтр `.gitignore` — влияет на всё |
| `ui_main._show_diff_dialog` | Пользователь видит diff перед apply |
| `ui_main._ensure_gitignore` | Дописывает `logs/`, `dumps/`, `*.bak` |
