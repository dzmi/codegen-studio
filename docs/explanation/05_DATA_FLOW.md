# Поток данных (Data Flow)

## 1. Статический анализ (AST)
Модуль `ast_analyzer` (если используется) или встроенные средства извлекают структуру кода (классы, методы, аргументы). Это нужно для работы `replace_symbol`.

## 2. Поток данных Codegen
1. Пользователь вставляет JSON в интерфейс.
2. `normalize_actions()` приводит JSON к внутреннему формату `Action`.
3. `validate()` проверяет синтаксис, пути и наличие блоков (через AST или поиск строк).
4. `simulate()` строит предпросмотр (diff) в памяти.
5. Пользователь проверяет Diff и нажимает «Применить».
6. `apply_simulation()` атомарно пишет файлы:
   - Создает `.bak` бэкапы.
   - Записывает новый код.
   - При ошибке — восстанавливает бэкапы и удаляет созданные файлы.

## 3. Взаимодействие с LLM
- Связь только через буфер обмена (промпт → LLM → JSON).
- Приложение не делает сетевых запросов (полная приватность).
