# Архитектура (arc42)

## 1. Введение и цели
Codegen Studio — офлайн-инструмент для применения JSON-инструкций к коду. Работает без встроенного ИИ.

## 2. Ограничения
- Python 3.10+ (Tkinter).
- Ноль обязательных внешних зависимостей (опционально `pygments` и `dulwich`).
- Никакого сетевого кода.

## 3. Контекст
Пользователь копирует промпт во внешнюю LLM (ChatGPT/Claude), получает JSON, вставляет в программу.

## 4. Строительные блоки
- `ui_main.py` — весь GUI (Tkinter).
- `codegen_core.py` — ядро (валидация, симуляция, транзакционное применение).
- `exporter.py` — экспорт JSON/ZIP с фильтрацией.
- `git_py.py` — работа с Git (через dulwich или subprocess).
- `logger.py` — логирование.
- `lite_highlighter.py` — подсветка синтаксиса.

## 5. Поток данных (Runtime)
1. Пользователь выбирает проект.
2. Вставляет JSON.
3. `codegen_core` валидирует и строит diff.
4. Пользователь подтверждает.
5. `apply_simulation` пишет файлы (создает `.bak`).
6. При сбое — атомарный откат.
